# 로방고 섬 (Robango Island) — 팩 설계 요약

이 문서는 구현 계획(`.omo/plans/durango-roblox-port.md`) §1, §4~§9와 착수 전 결정(ADR-01~09) 가운데 이 팩에 해당하는 내용을 요약한다. 계획 원문이 우선하며, 이 문서의 수치는 전부 신규 산정 초기 가설이다.

- 작업명: 「로방고 섬 / Robango Island」, 팩 slug `robango-island` (ADR-01).
- 장르: survival-coop 단독, crafting 모드 (ADR-02). 생성 명령: `lune run cli/forge new robango-island --genre survival-coop --mode crafting`.
- 트랙: ORIGINAL. 타이틀·지명·상품명·대사에 원작 표현을 쓰지 않는다.
- 이 팩은 core·genre 코드를 복사하거나 수정하지 않고 hook만 등록한다. 생성 파일(`EconConfig.luau`, `GenreConfig.luau`, `Assets.luau`, `ProcAssets.luau`, `SurvivalContent.luau`)은 손으로 고치지 않고 원본(yml)을 고친 뒤 codegen을 돌린다.

## 1. 목표·비목표·이상 상태 (계획 §1)

**영향 대상.** 모바일 우선 Roblox 플레이어(13세 이상 포함, 등급 Mild 목표), 1인 소유자, 팩·장르·core 작업을 하는 구현 에이전트, 다른 게임 팩(회귀 대상), IP 거리를 유지해야 하는 권리자.

**목표.**
1. 섬 생존·제작·조련·협동 정착 게임을 스테이징에 배포하고 출시 체크리스트를 통과한다.
2. P0 시스템마다 조합·게이팅·페이싱이 원작 체인과 다름을 차별화 표로 남긴다.
3. 출시 장애(대기열·저장 병목)와 반복 콘텐츠 피로에 대한 대응을 설계와 QA로 고정한다.
4. forge 하드 룰(유료 랜덤 금지, Rng + 주입 clock, codegen, Steal-a 구조 금지, 스테이징 전용 배포)을 위반 0으로 지킨다.

**비목표.** 서버 간 끊김 없는 단일 월드, 원작 이름·스토리·아트 사용, 원작 BM 이식, 50명 초과 섬·대규모 전투, 매출·CCU 예측, Studio 실행·프로덕션 배포 자동 수행.

**이상 상태(관찰 가능).**
| 대상 | 이상 상태 | 증거 |
|---|---|---|
| 신규 플레이어 | 첫 5분 안에 채집 → 제작 → 정착지 선언 → 첫 의뢰를 1회 완주 | tutorial_step / tutorial_complete, D1 재방문 |
| 재방문 플레이어 | 텔레포트·재접속 후 본거지섬과 인벤토리가 바이트 동일 | forge replay MATCH, 인벤토리 해시 |
| 소유자 | 어떤 Robux 상품도 확률 결과에 닿지 않음 | forge check econ + 카탈로그 lint |
| 출시 직후 | 동시 입장 시 대기 지연 상한 이하, 데이터 손실 0 | QA-SPIKE-01 |
| 권리자 관점 | 출시 문자열·애셋·이름에 원작 표현 0건 | QA-PROV-01, QA-NAME-01 |
| 다른 팩 | core/genre 변경 후에도 모든 팩 테스트 PASS | forge check --all |

## 4. 시스템 설계 (계획 §4)

공통: 서버 권위, 모든 확률은 `Rng.new(seed):fork(label)`, 시간은 주입 clock, 데이터는 `content.yml`/`econ.yml` → codegen.

- **생존.** 체력·허기·노출(기후) 3게이지 + 자동 회복 스태미나. 노출은 바이옴별 4단계, 의복 저항 점수로 완화. 안전 지역 사망은 소지품 보존 + 짧은 부활 대기, 옵트인 위험 구역은 반입품만 드롭. 가방은 슬롯 20 + 무게 한도, 유료 상품은 본거지 창고만 넓히고 휴대 용량은 늘리지 않는다.
- **제작.** 레시피 슬롯은 "태그 + 최소 등급"을 요구한다. 결과 품질 = 재료 품질 평균, 숙련 단계가 상한. 대성공·잠재 속성은 `Rng:fork("craft-crit")`, `Rng:fork("latent")`. 작업대 등급이 레시피를 열고, 맡김 제작은 저장된 시작 시각 + 주입 clock. 내구도는 수리할 때마다 최대치가 조금씩 줄어든다.
- **기술 관문.** 섬 접근 → 재료 → 작업대의 순차 관문. 관문 정의는 `content.yml`.
- **직업·숙련.** 고정 직업 대신 배경 3택(채집꾼·장인·탐사가, 가칭, 무료 변경). 숙련은 행동 기반 XP와 6개 공예 분야, 상한 = 도구 등급 + 숙련 단계. 연구는 행동형 "현장 기록" 과제. 숙련 초기화는 고정 효과의 결정적 상품만 허용. 위치는 `genres/survival-coop/module/Skills.luau` 신설, crafting 슬라이스 마커 2 → 3 (ADR-03).
- **건축·정착.** 그리드 32×32, 구획 4 상한. 배치 검증은 서버. 같은 구조물이 재료 태그로 외형만 바뀐다. 유지비 없음, 방치 시 휴면(풍화 외형), 구획 밖 방치물은 소유자에게 반환(약탈 불가).

## 5. 레벨 디자인 (계획 §5)

| 플레이스 | 역할 | 인원(P0) |
|---|---|---|
| 첫 상륙지 | 손으로 만든 온보딩 섬, 개인 고갈 없는 노드 | 8 |
| 본거지섬 | 개인·캠프 정착지(구획 4), 예약 서버 1개 = 쓰기 주체 1개 | 8 |
| 교역항 | 공유 허브(장터·의뢰 보드·출항) | 8 |
| 탐사 항로 | 항로 카드로 시드 조립되는 휘발성 자원섬, 24시간마다 교체(ADR-05) | 8 |
| 분쟁 암초(P2) | 옵트인 캠프 대 캠프 공성 | 8(4 대 4) |

- 서버당 8명, 캠프원 4명 유지(ADR-04).
- 섬 템플릿 = 수작업 모듈 + 시드 조립. P0: 첫 상륙지 1, 본거지 지형 프리셋 3, 탐사 항로 모듈 12. 저장은 `{templateId, seed, delta, expiresAt}`.
- 생물군계: P0 온대 숲·해안 습지, P1 건조 고원·화산 해안, P2 한랭 툰드라.
- 난이도 밴드 4단계(잔잔·거친·험한·원정)는 레벨이 아니라 장비·저항 점수로 진입한다.
- 본거지섬은 출항 부두·작업대 구역·창고·의뢰 게시판을 고정 슬롯으로 두고, 구획 확장은 탐사 기록(칭호·확장권)으로 연다.

## 6. 생물·AI (계획 §6)

- P0 아키타입 6종(도약형·돌진형·꼬리형·포효형·스캐빈저·초식 무리형) × 종 12.
- 행동 플래그 passive / retaliate / aggressive. 상태 기계: 수면·감지·추적·텔레그래프·타격·리쉬 귀환·동면. NPC 32 상한.
- 무리: 리더 + 구성원, 피격 시 경보 반경 안에서 합류(연쇄 상한).
- 처치는 비유혈 "무력화 → 소멸" 연출, 부위별 채집 수확.
- 조련: 기절 게이지 → `Rng.new(seed):fork("tame")` 판정, 실패해도 도주하지 않고 재시도 가능. Robux는 조련 결과에 영향 0.
- 탈것: 종별 속도·적재 고정. 유료 탈것은 외형만 다르다.

## 7. 소셜·캠프·거래·PvP (계획 §7)

- 캠프(4인): 공동 건설 목표 완료 수로 공용 시설과 시즌 공성 리그 자격을 연다.
- 친구 본거지섬 방문: 읽기·도움 행동만, 가져가기 불가.
- 채팅: TextChatService 필터 필수, 필터 실패 시 미전송.
- 장터: 서버 권위 원장, 등록 수수료가 소프트 싱크. Robux로 산 아이템은 전부 거래 불가.
- PvP: 옵트인 분쟁 암초의 캠프 대 캠프 팀 공성만. 개인 기지 약탈·"Steal a ..." 구조 금지.
- 경제 무결성: 거래 자격 게이트(계정 나이·플레이 시간·튜토리얼 완료), 일일 거래 스로틀, 캠프 재가입 쿨다운, 이상 탐지 플래그 → 사람 검토, 원장 영수증 재생 방식의 부분 롤백.

## 8. 경제·BM (계획 §8, ADR-07)

**재화.** 소프트 재화는 **조개돈** 1종뿐이다. Robux → 조개돈 환전 상품은 없다. 지갑은 음수가 될 수 없다.

**가격표(결정적 상품만, 초기 가설).**
| 상품 | 종류 | Robux | 효과 |

**금지.** 상자·뽑기·랜덤 꾸러미, 행운·드롭·성공률 부스트, 시간 단축 이동권, 조련 성공 보조, 유료·무료 재료를 섞는 랜덤 강화, 구독 혜택의 확률 변경. 가격·확률 변경은 사람이 머지하는 PR로만 한다.

**리텐션.** 일일 의뢰 3개, 24시간 항로 교체, 주간 공동 프로젝트로 짧은 일일 재방문 루프를 만든다.

## 9. 세계관·NPC·퀘스트·튜토리얼 (계획 §9)

**전제.** 「조수 균열」 이후 대양 한가운데에 지형이 수시로 바뀌는 섬들이 떠올랐다. 섬에는 멸종했다고 여겨진 대형 파충류와 낯선 식생이 산다. 플레이어는 민간 **항로단**의 일원으로, 후원 세력의 의뢰를 받아 섬을 조사하고 정착지를 세운다. 섬이 왜 떠오르는지는 시즌마다 조금씩 드러나는 열린 미스터리이며, 끝에는 "함께 지은 것이 남는다"는 정서를 둔다.

**세력 3개(가칭).**
| 세력 | 동기 | 의뢰 | 보상 |
|---|---|---|---|
| 항로 측량회 | 지도와 항로로 이익을 낸다 | 지점 발견, 항로 기록, 표류물 회수 | 출항 장식, 지도 테마 |
| 장인 길드 연합 | 섬 재료로 새 공예를 만든다 | 품질 등급 납품, 공동 건설 | 레시피, 건축 외형 |
| 섬 생태 보존단 | 섬 생태를 기록·보호한다 | 생물 관찰·사진, 서식지 복원 | 도감 항목, 조련 장식 |

**톤.** 현실 기반 + 가벼운 코미디, 비유혈.

**NPC.** 세력별 현장 연락원 3명 + 교역항 상주 NPC 4명(조선공·감정사·게시판 관리인·우체부). 대사는 `locale/strings.csv`.

**퀘스트.** 첫날 고정 의뢰 3개 → 장기 목표 보드. 일일 의뢰 3개는 `Rng.new(seed):fork("contract")`, seed = 플레이어 ID + 일자 키. 세력 신뢰도 5단계, 후원 꾸러미는 고정 구성. M2는 Tutorial.luau, M3는 survival-coop Contracts(ADR-02).

**튜토리얼(첫 5분).** 도착 장면(즉시 건너뛰기 가능) → 개인 구역 채집 → 돌도끼 제작 → 정착지 선언 → 첫 의뢰 수락·납품. 한 지점에서 하나만 가르친다.

**출처 검사.** 출시되는 모든 문자열은 n-gram 대조, 금칙 고유명 lint, provenance(사이드카 파일) 검사를 통과해야 한다(ADR-06, `provenance` check 단계).
