# Robango icon provenance

Date: 2026-10-21. Tool: `bun C:/Users/sook/code/rmb-lanes/_tools/imagegen.mjs`, Responses API built-in image_generation; script orchestrator model `gpt-6.1-sol`; header identifies image backend as `gpt-image-2-codex` (actual backend version not returned). Source art is original generated artwork, not code-drawn silhouettes. No Roblox uploads.

Every atlas requests high quality, transparent PNG, 1024x1024; actual returned dimensions are inspected by the slicer rather than assumed. Atlas 01 uses `atlas-01-prompt.txt`; all remaining exact prompts and per-cell logical keys are retained in `jobs.json`, with atlas 01 supplied as the style reference. `keys.json` defines row-major cell ordering. Each 96x96 icon is cropped from its corresponding atlas cell and resized using Bun.Image. No text or labels are baked into the icons.

The slicer insets cell boundaries by 5 percent before resizing to remove small
neighboring-cell fragments visible on the first contact row. Atlas files remain
unchanged original generations. No replacement shapes are drawn.
Disconnected alpha components touching the cropped cell boundary and smaller
than one quarter of the largest silhouette component are cleared as neighboring
cell bleed. Interior components and the main generated silhouette are retained.

Commercial API rights are not independently verified by this lane; the manifest identifies the actual tool rather than falsely claiming a forge-procgen origin. Local files remain NotUploaded, assetId 0.
